# LeetCode Extra

Problems solved outside [Striver's A2Z Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z).

Organized by difficulty:

```
leetcode-extra/
├── easy/
├── medium/
└── hard/
```

## Adding a problem

1. Create `leetcode-extra/<difficulty>/LXXXX_Problem_Name/`
2. Copy templates from `/templates`
3. Set frontmatter: `sheet: leetcode-extra`
4. Run `python3 scripts/update_readme_stats.py`
