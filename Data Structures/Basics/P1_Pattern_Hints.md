# P1 Pattern Hints

Only the pending patterns are listed here. Each hint is short on purpose so it helps without exposing the full solution.

## Pattern 17
Use a row-wise letter increment. Restart from A on every row and stop at the row number.

## Pattern 18
Build a centered alphabet palindrome. Let the left half rise to the middle, then mirror it back.

## Pattern 19
Work backward from the alphabet end. Each next row starts one step earlier than the previous row.

## Pattern 20
Think in terms of two mirrored halves with a shrinking gap. The gap size changes by a fixed row formula.

## Pattern 21
Draw only the outer border of a square. Interior positions stay blank.

## Pattern 22
Use a value based on the minimum distance to any edge. That distance decides the number to print.
